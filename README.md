This is my attempt at performing network optimization duties as a radio access network engineer for a large 5G network service provider.

From a raw drive-test dataset, I prescribed corrective actions to a 5G network by analyzing key performance indicators and quality of experience (QoE) metrics. I applied data analysis and RF engineering principles to accomplish the following:

1. I inspected the raw data for quality, consistency, and accuracy.
2. I located KPI statistical distributions that measured below target requirements.
3. I fused the KPI categories together to identify tests with the poorest QoE. 
4. I validated KPIs using primary and secondary measurement methods.
5. I evaluated KPI-to-KPI statistical relationships for root-cause analysis.
6. I performed spatial analyses to observe site specific network problems.
